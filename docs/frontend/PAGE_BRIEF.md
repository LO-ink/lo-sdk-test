# Проверка SDK

Стенд для разработчиков: запустить проверки, увидеть ошибки, сохранить отчёт. React/Vite и существующие SDK сохраняются. Приоритет — рабочий инструмент с короткими подписями, системным шрифтом и одной основной кнопкой; без декоративной шапки и пояснений об устройстве самого интерфейса.

Путь: открыть → нажать «Проверить все мосты» → при необходимости ответить на запрос LO о сообщениях → дождаться результата → раскрыть ошибки или скачать отчёт. Все проверки, включая сообщения и файлы бота, включены всегда; блок выбора и пояснений со стартового экрана убран. Подпись, разрешение и сохранение на сервере выполняются в этом же прогоне. Нет предварительной настройки на других экранах. Запрос разрешения начинается синхронно из пользовательского нажатия; отказ и сбой сохраняются в отчёте и блокируют отправку.

Основные разделы: «Проверка» и «Вручную». Во втором — методы приложения LO, бота, данные запуска и журнал. Пользовательский термин — «Приложение LO», а не «хост». API-имена и ответы видны при раскрытии результатов; версии SDK внизу или в JSON. Результат показывает покрытие каталога мостов, включая непроверенные методы и события в знаменателе. Ответ API отдельно от подтверждённого эффекта. По умолчанию отчёт показывает ошибки. Во время прогона доступны прогресс, текущая операция и остановка.

Проверить: разрешение из одного нажатия, подпись до сохранения согласия, сохранение до отправки, отказ и сбой сервера без отправки, отмена и очистка, типизация/build/format, браузер 320/390/1280 px и живой LO. Основная кнопка видна сразу. Safe area и нижний отступ сохраняются. Оплата, внешние переходы, очистка и права требуют явного нажатия внутри этого же прогона; без тестовых параметров — «Не проверено». Закрытие и sendData доступны после сохранения результата, с подтверждением после повторного открытия.

Версии открыты по умолчанию; список можно свернуть стандартным шевроном. Номер сборки LO SDK Test виден над версиями и включён в JSON-отчёт. Для каждой версии показывается актуальность относительно main на GitHub по sourceCommit: совпадение, доступное обновление, сборка новее main или отсутствие подтверждения. Время проверки видно рядом с источником; сетевой сбой не выдаётся за актуальную версию. Сервер кэширует публичную проверку, не используя токены.

Лента: текущий кейс с названием моста, последние семь шагов и раскрытие всех предыдущих. Галочка означает подтверждённый результат, крест — ошибку, API — только ответ, тире — непроверенный результат или пропуск. Лента обновляется после каждого шага. Вибрация и цвета требуют подтверждения физического эффекта; кнопки — события, датчики — данных. Мосты тестируются независимо. Синтетическая браузерная QA не считается живой проверкой LO.

Системная тема: в текущем прогоне есть кнопка начала наблюдения за реальными themeChanged; пользователь переключает оформление устройства туда и обратно. Каждый мост подтверждается отдельно только по двум событиям и совпавшим colorScheme. CSS-тема стенда не выдаётся за смену системной темы. Подпись сравнения версий центрирована.
